# Recursos gráficos

Los GIFs están incluidos como valores predeterminados para ES y BR en
`config/settings.py`: `Puerta%201.gif` para puerta cerrada y espera, y
`DulcesGIF.gif` para ganar y `RobaGIF.gif` para perder. Las ocho variables `ES_DOOR_*_GIF` y
`BR_DOOR_*_GIF` permiten sustituir cada imagen de forma independiente.
Si están ausentes o vacías, se utiliza el GIF predeterminado. No es necesario subir
archivos GIF a este directorio. Verifica la reproducción en Discord al desplegar.
